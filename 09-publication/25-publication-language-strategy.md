# Publication-Language Strategy

**Status:** Approved

## Decision

Publish the existing Blueprint in its authoritative source language, currently English, while preserving Brazilian Portuguese product terms, examples, identifiers, formats, and semantics exactly where approved. Clearly state that documentation language does not change Nexora’s pt-BR-first product contract.

Do not launch a partial mirrored Portuguese documentation tree. Provide a Portuguese orientation summary and terminology aid only after native review, with explicit links to the authoritative English source and a scope statement. Full bilingual publication requires translated-source ownership, parity validation, route strategy, search support, review capacity, and a separate approval.

Machine translation may be offered only as a browser/user aid, never labelled authoritative or indexed as Blueprint truth.

## Validation

Check language attributes, pronunciation-sensitive abbreviations, Portuguese diacritics, mixed-language search, terminology links, locale labels, and that no translated summary changes approved meaning.
