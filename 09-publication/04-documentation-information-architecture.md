# Documentation Information Architecture

**Status:** Approved

## Decision

Use a source-aligned information architecture with four reader entry dimensions:

- **Blueprint phases** as the primary authoritative hierarchy;
- **Decisions and ADRs** for governance and history;
- **Indexes and mappings** for pages, templates, capabilities, and increments; and
- **Guided journeys** for orientation and portfolio review.

Repository sections remain canonical. Reader-oriented indexes are generated projections and never relocate or duplicate source truth. Phase ordering follows the approved roadmap. Cross-phase subjects use generated collections and backlinks rather than a second taxonomy tree.

The site exposes the current phase, document type, status, owner when recorded, source path, and canonical URL. Administrative Dashboard planning remains visibly distinct from the Phase 2B Admin architecture and later implementation contracts.

## Validation

Coverage proves that every eligible source has one canonical route, one primary section, and any applicable generated memberships. Orphan routes, duplicate primary placement, and manually duplicated authoritative content block publication.
