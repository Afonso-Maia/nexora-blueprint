# Product Decisions

Product decisions are recorded in their relevant topic files using the statuses Proposed, Approved, Superseded, or Deprecated. Cross-cutting or expensive-to-reverse decisions also receive an [ADR](../adrs/README.md).

Phase 1, Phase 2A, and Phase 2B decisions are approved. Product Structure decisions are indexed in [Product Structure Architecture](../03-product-structure/README.md).
