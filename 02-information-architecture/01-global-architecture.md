# Global Product Architecture

**Status:** Approved

```text
Nexora
├── Customer Website
│   ├── Discovery
│   ├── Shopping
│   ├── Purchase
│   ├── Orders
│   └── Account
├── AI Shopping Assistant
├── PC Builder
├── Support Center
├── Customer Authentication
├── Administrative Dashboard
└── Shared Services
    ├── Search
    ├── Catalog
    ├── Inventory
    ├── Pricing
    ├── Reviews
    ├── Promotions
    ├── Notifications
    └── User Profiles
```

These products share identity, design language, and commerce services.

| Domain | Purpose |
| --- | --- |
| Discovery | Search and browse |
| Catalog | Product information |
| Purchase | Cart and checkout |
| Customer | Accounts and orders |
| Support | Help and after-sales |
| AI | Recommendations and guidance |
| PC Builder | Compatibility and custom PCs |
| Admin | Commerce operations |
| Marketing | Campaigns and editorial content |

Lifecycle: `Land → Discover → Evaluate → Compare → Configure (optional) → Purchase → Track → Receive → Support → Return`
