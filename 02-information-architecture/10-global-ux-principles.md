# Global UX Principles

**Status:** Approved

- A fast path always exists.
- Guidance is optional.
- Recommendations are explainable.
- Complexity is progressively disclosed.
- Comparison reduces cognitive load.
- AI augments user control.
- Intent configures but does not conceal.
- Meaningful context persists.

These principles apply across the [global architecture](01-global-architecture.md) and extend the approved [product principles](../00-overview/product-principles.md).
