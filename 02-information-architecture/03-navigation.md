# Navigation

**Status:** Approved

**Decision:** Hybrid task navigation with one category mega menu.

Primary navigation contains Home, Categories, Deals, PC Builder, and Support. Global header utilities contain Universal Search, AI, Account, Wishlist, Compare, and Cart.

## Rules

- `Categories` is the only mega-menu entry.
- Search is visually and behaviorally primary.
- Navigation exposes high-value tasks rather than every content type.
- Mobile preserves the same conceptual hierarchy.
- New content types do not automatically become top-level navigation.

Responsive navigation behavior is governed by the completed [Design System and Experience Specification](../04-design-system/README.md); exact page composition remains part of wireframing.
