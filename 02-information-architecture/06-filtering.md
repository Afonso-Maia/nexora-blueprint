# Filtering

**Status:** Approved

**Decision:** Attribute-driven dynamic filtering.

Hierarchy: Quick Filters, Core Filters, Category Filters, Compatibility Filters, then AI Filters.

## Rules

- Categories determine eligible attributes; the active result set determines useful values.
- Hide filters without decision value and values absent from the result set.
- Put high-impact filters first.
- Preserve selections during evaluation.
- Keep sorting independent from filtering.
- Represent filter state conceptually in shareable URLs.
- Mobile preserves the hierarchy in a space-appropriate form.
- Compatibility filters use the shared compatibility model.
- AI filters supplement rather than replace technical filters.
- Users can inspect, modify, or clear intent-driven effects.
- Labels and units remain consistent.
