# Universal Search

**Status:** Approved

**Decision:** Universal Discovery Engine.

Search indexes products, categories, brands, collections, buying guides, PC builds, support articles and FAQs, and promotions. Products rank first by default for commercial queries; supporting types appear in clearly separated groups.

Ranking may consider relevance, availability, compatibility, popularity, rating, and user context. Sponsored results, if introduced, must be labeled. AI suggestions remain distinguishable from deterministic results. Every new content type declares whether and how it participates.

## Capabilities

- Global, persistent access
- Instant suggestions and autocomplete
- Typo tolerance, synonyms, aliases, and abbreviations
- Natural-language queries
- Recent and trending searches
- Keyboard navigation
- Dynamic filters
- Zero-result recovery
- Optional AI follow-up

Voice and image search are deferred.
